
 一、项目概述

开发一个单文件 HTML 计分器，用于明日方舟“集成战略”类比赛。用户输入原始分、用时、藏品数量，勾选关卡加分和额外加分项，填写临时招募数量，勾选或填写扣分项，程序实时计算最终得分。所有加减分项的配置可在线编辑，计分明细可导出。

 二、技术方案

- 单文件 HTML（HTML + CSS + JS 写在一个 `.html` 文件里），双击即可在浏览器打开。
- 适配手机和电脑。
-配置数据自动保存：使用 `localStorage` 保存各分区的加减分项配置，下次打开自动恢复。
- 计分数据不自动保存：当前选手的计分输入不写入 localStorage，刷新页面会重置。用户可通过“导出”按钮保存明细。
- 配置含 `version` 字段：修改默认配置后需把 `version` 加 1，否则浏览器中已保存的旧配置会覆盖新默认值。
- 跨设备 / 跨浏览器：配置默认只存在本浏览器（localStorage 按「浏览器 + 来源」隔离）。搬运方式有两种：「导出定制 HTML」——配置随文件走，拷过去打开即生效；「导出配置 / 导入配置」——只同步分区规则，保留当前已填写的计分输入。
- 内嵌配置优先级：HTML 内嵌的配置（`<script id="default-config">`）与上次在本机生效的不是同一份（指纹不同）时，内嵌配置优先；同一份文件再次打开则仍以本机存档为准，保留本机改动。
- 不需要后端、不需要数据库、不需要构建工具**。

 三、界面结构

计分模式下有四个可操作区，每个区标题旁有一个 “修改配置”按钮。

 1. 基础结算（输入型）

- 原始分：数字输入框。
- 用时：数字输入框（单位：小时）。根据配置的时段规则自动计算加分或扣分。
  - 默认规则（区间含两端，按顺序优先命中，因此恰好 2 小时记 +30 分）：
    - 0～2 小时：+30 分
    - 2～4 小时：不加分不扣分
    - 超过 4 小时：每超 1 小时 −20 分（默认不足 1 小时按 1 小时计，可改为按实际小数计算）
  - 时段数量、边界值、加减分值均可在该分区的配置模式编辑。
- 藏品数量：数字输入框。加分 = 藏品数量 × 单个藏品加分数（默认 +5/个，可在配置模式修改）。

 2. 关卡加分（勾选型）

- 以复选框列表形式展示。
- 每个条目包含：关卡名称、加分值。
- 勾选后加上对应分数，取消勾选则移除。同一关卡仅加分一次。
- 默认条目：
  - 无效验尸 +200
  - 同域共存 +300
- 配置模式可增加、删除条目，修改名称和分数。

 3. 额外加分

- 分为两类：
  - 携带特殊藏品：勾选型，勾选即加分（默认 +100 分）。
  - 临时招募：输入型，输入数量，加分 = 数量 × 单个加分数。
    - 六星：+50/个
    - 五星：+20/个
    - 四星：+10/个
- 配置模式可增加、删除条目，修改名称、分数、单位，并选择类型（勾选型 / 输入型 / 固定型 / 阈值型）；还可填写「分组」标题，用于在计分界面显示小标题。

 4. 扣分项（标题红色）

- 条目形式与额外加分类似，可选择勾选型、输入型、固定型或阈值型。
- 默认条目：
  - 取钱超过 100 锭：阈值型，填写取钱总数（含 100 锭），超出 100 锭的部分每锭 −10 分（即 (数量 − 100) × −10）
  - 携带特殊藏品：−100（勾选型）
- 配置模式可增加、删除条目，修改名称、扣分数值，选择类型。

总分计算

最终得分 = 原始分 + 基础结算加分 + 关卡加分 + 额外加分 − 扣分项合计

实时计算并显示：
- 每个项目的小计
- 加分合计
- 扣分合计
- 最终得分

加分项用绿色标识，扣分项用红色标识。

四、分区配置模式

- 每个计分分区标题旁有 “修改配置” 按钮。
- 点击后，该分区进入配置界面，其他分区保持计分状态；当前分区已填写的计分输入会被保留，点击「保存」后继续有效。
- 配置界面中可：
  - 增加条目
  - 删除条目
  - 编辑条目名称、分值、单位、阈值、分组、类型（勾选型 / 输入型 / 固定型 / 阈值型）
  - 四种类型的含义：勾选型 = 勾选即加/扣分；输入型 = 数量 × 分值；固定型 = 恒定加/扣分；阈值型 = 超出阈值部分 × 分值
  - 调整顺序（可选）
- 每个配置界面有：
  - “恢复默认”按钮：恢复该分区的默认配置（内置默认值，或定制 HTML 内嵌的默认值）。
  - “保存” 按钮：保存配置到 `localStorage`，退出该分区配置模式，立即影响计分。
  - “取消”按钮（可选）：不保存，退出配置模式。
- 配置数据自动保存，下次打开页面仍然保留。

五、导出功能

在计分模式下提供以下导出按钮：

1. 导出 CSV：
   - 包含：比赛名称、选手/队伍名称、日期、原始分、每个加分项明细（名称、数量/勾选、单位分值、小计）、加分合计、每个扣分项明细、扣分合计、最终得分。
   - CSV 文件需加 BOM（`\ufeff`），防止 Excel 打开中文乱码。
   - 防公式注入：以 `=`、`+`、`-`、`@` 或制表符 / 回车开头、且不是纯数字的文本会前置一个 `'`，避免 Excel 把条目名之类的内容当公式执行（`-200`、`+30` 这类分值仍按数值输出）。
2. 导出 JSON：用于备份和导入（含分区配置与当前计分输入）。
3. 导出配置 / 导入配置：
   - 导出配置只含分区配置；导入配置只覆盖分区配置，保留当前已填写的计分输入。
   - 用于比赛现场在多台设备之间同步计分规则。
4. 导出定制 HTML：导出「自带当前配置」的 HTML 副本（配置写进文件内的内嵌配置块），拷到其它设备或其它浏览器打开即可直接使用同一套规则，无需再导入。
5. 打印 / 导出 PDF：调用 `window.print()` 实现。
