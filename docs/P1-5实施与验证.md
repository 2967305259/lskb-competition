# P1-5 正式积分、场次统计与晋级合同

日期：2026-11-15。实现分支：`p1-5-formal-settlement`。

## 已实现

- 新增 `formal_match.py` 作为正式整场的唯一判定入口：根记录、`match_type=match`、排除日程子段和表演赛。
- 分时比赛统一按根比赛提交成绩、确认结算、计算积分和统计胜负；子段只承载日程。
- 成绩提交只保存待结算数据；管理员“确认结束并结算”后才进入积分重算。
- 弃权立即记录胜负，但积分仍保持待结算；已交成绩保留，未交的弃权方记录明确的 0 分，对手可补交。
- 0 分与未提交分离，审核驳回不撤回已结算积分或胜负。
- 选手战绩 API 默认按当前赛季统计，`?season=all` 才返回跨届累计；总战绩不受最近 50 场列表限制。
- 队伍排名使用竞争排名（1/1/3），晋级按边界分数包含全部同分队伍。
- 排行榜、赛事结果和往届归档页面显示并列冠军、并列名次和跳号名次。

## 验证

```bash
python -m pytest -q --disable-warnings
```

结果：51 passed。覆盖整场一次结算、分段重复提交拒绝、弃权补交、显式 0 分、审核不撤分、当前/累计战绩隔离、表演赛与子段排除、并列排名和边界晋级。

表演赛的计分政策仍按项目范围暂缓；本次实现只确保它不会被误计入正式场次与选手正式战绩。
