# P1-6 人工调整分与审计

日期：2026-11-16。

## 已实现

- 人工调整统一通过 `create_score_adjustment()` 写入独立账本，不再直接覆盖比赛累计分。
- 队员积分明确拆分为：比赛累计、有效调整分、最终积分。
- 重算始终按“已结算比赛分 + 有效调整分”重建，队伍再乘所属赛季 bonus。
- 调整创建和撤销审计均保存赛季、成员、调整值、原因以及前后积分账本。
- 调整记录的赛季、成员、操作人、分值、原因和创建时间不可改写；撤销只能通过专用撤销字段完成。
- `data-report` 增加人工调整账本与成员积分拆分，旧差额不会自动伪造为调整分。
- 管理员队伍详情页显示比赛累计、有效调整和最终积分。
