# P1-1 新赛季向导与配置继承

日期：2026-11-16。

## 已实现

- 新赛季向导支持独立继承报名起止时间、比赛起止时间、晋级数量、队伍人数、未满员开赛设置和轮播条目。
- 日期按上一届原值复制，不做自动平移；空日期可以继承为空。
- 向导提示核对沿用的全局规则和赛道，提供直达入口。归档保留上届快照。新届报名初始关闭，由管理员核对配置后手动开放。
- 轮播只复制数据库条目和路径，不复制素材文件；旧赛季条目保持不变。
- 未勾选继承时保持原有行为：时间为空、晋级数量归零，队伍全局配置保持原值。
- `new_season` 审计日志记录继承项、复制条目数量和继承后的关键值。

## 验证

```bash
python -m pytest -q --disable-warnings
```

结果：59 passed。新增覆盖全量继承、无继承默认行为、空日期继承和轮播条目隔离。
